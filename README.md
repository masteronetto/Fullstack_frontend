# Kebumy Frontend

## Instrucciones de instalación

1. **Clona el repositorio:**
   ```bash
   git clone <URL_DEL_REPOSITORIO>
   cd FrontendKebumy
   ```

2. **Instala las dependencias:**
   ```bash
   npm install
   ```

---

## Instrucciones de ejecución

### Ejecución general (modo desarrollo)

1. Asegúrate de que el backend esté corriendo (por defecto en http://localhost:3000).
2. Inicia el frontend:
   ```bash
   npm run dev
   ```
3. Abre tu navegador en [http://localhost:5173](http://localhost:5173)

---

### Ejecución de tests

1. Ejecuta los tests con:
   ```bash
   npm test
   ```
   o, si usas Vitest:
   ```bash
   npx vitest run
   ```
2. Los resultados aparecerán en la terminal.

---

## Notas
- El frontend está construido con React + Vite.
- Para pruebas de integración, asegúrate de que el backend esté disponible y configurado correctamente.
- Si tienes problemas con dependencias, ejecuta `npm install` nuevamente.
